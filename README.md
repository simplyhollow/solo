# Solo 5e Companion

A guided solo D&D 5e companion app for learning and playing without a DM.

## Features
- Roll-first character creation (no deep rules knowledge needed)
- Full SRD classes, multiclassing, backgrounds
- Abilities & Spellbook panel
- Chat-style adventure with automatic skill rolls
- Optional AI DM via Grok or OpenAI API
- Works offline after first load (PWA)
- Installable on phones like a real app

## How to host
1. Upload the contents of this folder to any static host:
   - GitHub Pages
   - Netlify Drop
   - Vercel
   - Your own server
2. Open the site on a phone.
3. Use the browser menu → “Add to Home Screen” / “Install App”.
4. It opens full-screen like a native app.

## API (optional)
For the AI DM, get a key at:
- https://console.x.ai (Grok)
- https://platform.openai.com/api-keys (OpenAI)

Paste it in the Adventure panel. The key stays only in your browser.
